# 05-retrospective

Thư mục này lưu retrospective và bài học sau mỗi sprint hoặc task lớn.

Quy ước tên file:

```text
sprint-<number>.md
```

Mỗi retrospective nên có:

- outcome
- việc đã ship
- lỗi hoặc blocker chính
- quyết định quan trọng
- bài học rút ra
- follow-up cụ thể

Mục tiêu là giúp LeeJ Agent giảm lỗi lặp lại, cải thiện điều phối Worker, và giữ lịch sử tiến hóa của hệ thống. Retrospective không thay thế log chi tiết trong `03-logs`; nó là bản chắt lọc sau sprint.
