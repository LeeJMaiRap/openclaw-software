# 00-overview

Thư mục này lưu bối cảnh tổng quan của dự án OpenClaw AI.

Nội dung phù hợp:

- yêu cầu ban đầu
- mục tiêu sản phẩm
- phạm vi sprint lớn
- problem statement
- stakeholder context
- ghi chú nền tảng giúp LeeJ Agent hiểu dự án trước khi lập kế hoạch

Không lưu task output, runtime log, hoặc retrospective tại đây. Dùng các thư mục chuyên biệt tương ứng trong vault.
